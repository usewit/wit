# Fonts

Wit uses the fonts in this folder before the ones installed on the
computer. Everything here is open (SIL Open Font License); each family's
licence is in `licenses/`.

| Font | Good for |
|---|---|
| EB Garamond | Classic book face for novels |
| Crimson Pro | Book text, a little more modern |
| Libre Baskerville | Baskerville, large and very readable |
| Literata | Made for long reading |
| Lora | Contemporary and warm |
| Alegreya | Literary, with a calligraphic touch |
| Source Serif 4 | Essays and non-fiction |
| Andika | Children learning to read |
| Atkinson Hyperlegible | Low vision and large print |
| Courier Prime | Screenplays, stage plays and manuscripts |

The static TTFs come from Google Fonts (Regular, Bold, Italic, Bold Italic).

## Your own fonts

Put fonts you may not share (Cambria, a bought typeface) in `fonts/local/`.
Wit uses them on this computer and Page setup lists them under "On this
computer", but git ignores that folder, so they are never published.

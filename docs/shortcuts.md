# Wit keyboard shortcuts

Every command is also in the command palette (**Ctrl+Shift+P** on Windows and
Linux, **⇧⌘P** on a Mac), where you can find it by typing part of its name.
**Alt+?** (**⌥?** on a Mac) shows this list inside Wit.

Mac keys: ⌘ Command · ⌥ Option · ⇧ Shift. Where macOS keeps a key for itself
(⌘Space opens Spotlight, ⇧⌘3–5 take screenshots, ⌘M minimises the window),
the Mac uses a different key, shown in the Mac column.

## Commands

| What | Windows and Linux | Mac |
|---|---|---|
| Show all commands | Ctrl+Shift+P or F1 | ⇧⌘P or F1 |
| Keyboard shortcuts | Alt+? | ⌥? |
| Settings | Ctrl+, | ⌘, |

## Document

| What | Windows and Linux | Mac |
|---|---|---|
| Open a folder | Alt+O or Ctrl+O | ⌥O or ⌘O |
| New book, essay, screenplay or play | Alt+N | ⌥⌘N or ⌥N |
| Save now (Wit also saves by itself) | Alt+S or Ctrl+S | ⌥S or ⌘S |
| Print PDF (white pages) | Alt+P or Ctrl+P | ⌥P or ⌘P |
| Proof PDF (as set up) | Alt+R | ⌥R |
| Export or print (PDF, Word, OpenDocument) | Alt+E | ⇧⌘E |
| Page setup | Alt+L | ⌥L |
| Revisions | Alt+H | ⌥H |
| Name a revision | Alt+Shift+S | ⌥⇧S |

## View

| What | Windows and Linux | Mac |
|---|---|---|
| Write mode (text only) | Alt+1 | ⌥1 |
| Split mode (text and pages) | Alt+2 | ⌥2 |
| Page mode (pages only) | Alt+3 | ⌥3 |
| Focus mode (Esc leaves it) | Alt+4 | ⌥4 |
| Changes since the latest revision | Alt+C | ⌥C |
| Toolbar | Alt+5 | ⌥5 |
| Formatting dock | Ctrl+Space or Alt+6 | ⌥⌘F or ⌥6 |
| Chapters (or scenes) sidebar | Alt+[ | ⌥⌘S or ⌥[ |
| Statistics sidebar | Alt+] | ⌥⌘I or ⌥] |
| Next theme | Alt+7 | ⌥7 |

| Smaller text | Alt+- | ⌥- |
| Text size back to 21 px | Alt+0 | ⌥0 |

| What | Windows and Linux | Mac |
|---|---|---|
| Bold | Ctrl+B | ⌘B |
| Italic | Ctrl+I | ⌘I |
| Underline | Ctrl+U | ⌘U |
| Dialogue dash (or type two hyphens) | Ctrl+D | ⌘D |

## Script (screenplays and plays)

| What | Windows and Linux | Mac |
|---|---|---|
| Scene heading (in a play: act or scene) | Ctrl+Shift+1 | ⌥⌘1 |
| Character | Ctrl+Shift+2 | ⌥⌘2 |
| Parenthetical | Ctrl+Shift+3 | ⌥⌘3 |
| Transition | Ctrl+Shift+4 | ⌥⌘4 |
| Centred text | Ctrl+Shift+5 | ⌥⌘5 |

Bold, italic and underline work in scripts too.
